# 💈 SaaS de Agendamento para Barbearias – Next.js + TypeScript

Este projeto é uma plataforma SaaS desenvolvida com [Next.js](https://nextjs.org/) e [TypeScript](https://www.typescriptlang.org/) voltada para agendamento de serviços em barbearias. Ele oferece uma experiência fluida e moderna tanto para clientes quanto para administradores, com recursos de autenticação, calendário, notificações e integração com WhatsApp.

## 🧩 Tecnologias Utilizadas

- **Next.js 15** – Framework React para aplicações fullstack
- **React 19** – Biblioteca para construção de interfaces
- **TypeScript 5** – Tipagem estática para JavaScript
- **TailwindCSS 4** – Estilização com utilitários
- **Radix UI** – Componentes acessíveis e estilizados
- **React Hook Form + Zod** – Formulários com validação robusta
- **Luxon + date-fns** – Manipulação de datas
- **JWT + jose** – Autenticação segura com tokens
- **Mongoose** – ODM para MongoDB
- **React Calendar** – Interface de agendamento
- **Embla Carousel + Keen Slider** – Carrosséis e sliders responsivos
- **QRCode + WhatsApp Web.js** – Integração com QR Code e envio de mensagens via WhatsApp
- **Sonner + React Toastify** – Notificações e feedbacks visuais
- **Cleave.js** – Formatação de campos de entrada
- **Node Schedule** – Agendamentos e tarefas recorrentes

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/Popotomimi/SaasBarber.git
```

```bash
# Instale as dependências
npm install
```

```bash
# Ambiente de desenvolvimento
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
